# ▲ てびき — 使い方ガイド

コーヒーの淹れ方から、近所のミスドへの行き方まで。
小さなことでも気軽にマニュアルにできる、いつでもどこでも使えるアプリです。


---

## はじめかた

### アプリを開く

ZIPを展開したフォルダで、ターミナルから以下を実行してください。

```bash
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開くとアプリが起動します。

### ホーム画面に追加する（スマホ推奨）

スマホで開くと「ホーム画面に追加」というバナーが表示されます。追加するとアイコンからすぐ起動できて、オフラインでも使えるようになります。

**Android（Chrome）の場合**
バナーの「追加する」をタップするだけです。

**iPhone（Safari）の場合**
画面下部の共有ボタン →「ホーム画面に追加」→「追加」の順にタップしてください。


---

## てびきを作る

ホーム画面の「新しいてびきを作る」をタップすると編集画面が開きます。

### タイトルをつける

画面上部の入力欄にてびきのタイトルを入力します。「コーヒーの淹れ方」「朝の準備ルーティン」など、なんでも構いません。

### タグをつける

タイトルの下にあるタグ（料理・食事、移動・外出、家事など）をタップして選べます。あとで見返すときの目印になります。

### ブロックを追加する

画面下部のボタンでブロックを追加していきます。

| ボタン | 用途 |
|--------|------|
| ＋ステップ | 手順を番号付きで書く。順番通りにやることを書くときに使います |
| ＋テキスト | 自由に文章を書く。補足説明やまとめに便利です |
| ＋見出し | セクションを分けるタイトル。長いてびきを整理するときに使います |
| ＋メモ欄 | 注意点やちょっとしたひとことを書く。黄色い背景で目立ちます |

### ブロックを並び替える

各ブロックの左端にある点6つのアイコンをドラッグすると、順番を入れ替えられます。スマホでは指でそのままスワイプするだけです。

### ブロックを削除する

ブロックにカーソルを乗せる（スマホではタップ）と右上に「×」が現れます。タップすると削除できます。

### 自動保存について

文字を入力するたびに自動で保存されます。上部に「保存しました」と表示されたら保存完了です。ブラウザを閉じても内容は残ります。


---

## てびきを見返す・管理する

ホームボタンを押すとホーム画面に戻り、保存済みのてびき一覧が表示されます。タップすると編集画面が開きます。

削除するには、てびきカードの右上にある「×」をタップしてください。

---

## PDFに書き出す

### 手順

1. 編集画面の右上「PDF出力」をタップ
2. 表紙のデザイン（6種類）を選ぶ
3. カラーテーマ（抹茶・琥珀・夜桜・海・墨・朱）を選ぶ
4. 好みで写真を表紙の背景に設定することもできます
5. 「PDFをダウンロード」をタップ

### PDFの構成

出力されるPDFは3部構成になっています。表紙（選んだデザイン）、本文（ブロックの内容が自動で組版されます）、裏表紙（アクセントカラーで統一されたシンプルなページ）です。

### データのバックアップとして

てびきのデータはブラウザ内にのみ保存されています。ブラウザのデータを消去すると失われてしまうため、大切なてびきは定期的にPDFとして書き出しておくことをおすすめします。

## よくある質問

**別のスマホやPCでも使いたい**
現時点ではデバイス間の同期には対応していません。PDFとして書き出して共有する方法をおすすめします。

**インターネットがない場所でも使える？**
ホーム画面に追加している場合はオフラインでも使えます。フォントの読み込みにネットが必要な場合がありますが、一度開いておけばキャッシュされます。

**データはどこに保存されている？**
ブラウザの localStorage という仕組みを使っています。サーバーには一切送信されません。
